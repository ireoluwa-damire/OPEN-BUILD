# OPEN//BUILD learning app: research and design pack

Prepared 27 October 2026, Africa/Lagos (WAT).

The strongest product direction is an adaptive coach that turns a specific goal into a sequence of things the learner can demonstrate. Give a provisional route after the first assessment; use seven days of teaching, recall checks, and applied tasks to improve it.

This is a bounded investigation of the public mobile web experience and relevant first-party publications, not an exhaustive inventory of every Duolingo version or its proprietary backend. Native iOS/Android builds, signed-in features, private model weights, and production source code were not inspected. REA performed the declared browser navigation and clicks in temporary profiles. Published descriptions are identified separately from observed runtime behavior.

The brief is reference material, not an instruction to register, contact anyone, publish a repository, or submit a project. No such external actions were taken.

Validation checked all selected screenshot and accessibility-text hashes, local document links, cited Evidence IDs, and eight proposed text/background contrast pairs. The reusable research code and candidate AI models were not run or benchmarked. The failed attempt to inspect incorrect-answer feedback is recorded in the teardown.
